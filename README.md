# Rime 虎码输入法配置

来自虎码[网盘](http://huma.ysepan.com/)，进行了一些整理和修改。

适用全平台

反查键改成 `!` (感叹号)

## 如何使用

安装方法：

1. 安装 Rime 输入法（如「鼠须管」、「中州韵」、「小狼豪」、「同文」等）
2. 电脑上安装 Release 里的 [字体包](https://github.com/wallleap/huma-rime-config/releases/download/%E8%99%8E%E7%A0%81v1.0.0/huma-fonts.zip)
3. 下载 [Release](https://github.com/wallleap/huma-rime-config/releases) 中 
Rime-config 压缩包，解压得到 `Rime` 目录，替换（或复制里面文件到） Rime 配置目录下（如 `~/Library/Rime`、`%APPDATA%\Rime` 等）
4. 重新部署输入法

## 主题

目前支持以下平台：

- 安卓 同文输入法
- macOS 鼠须管
- Windows 小狼豪
